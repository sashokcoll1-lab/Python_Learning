📘 День 10: Списки (list)
Теория:

1. Список — упорядоченная изменяемая коллекция элементов.

2. Создание списка:

python
numbers = [1, 2, 3, 4, 5]
fruits = ["яблоко", "банан", "апельсин"]
mixed = [1, "текст", True, 3.14]

3. Индексация:

list[0] — первый элемент

list[-1] — последний элемент

4. Срезы (slicing): list[start:stop:step]

5. Основные методы:

append() — добавить элемент в конец

insert() — вставить элемент по индексу

remove() — удалить элемент по значению

pop() — удалить элемент по индексу

sort() — отсортировать список

len() — получить длину списка

✅ Задание 10 (День 10)
Цель: Научиться создавать и работать со списками.

Задачи:

1. Создайте файл lesson_10.py.

2. Создание списков: Создайте три списка:

С числами от 1 до 5

С названиями трех любимых фруктов

Смешанный список с разными типами данных

3. Работа с элементами:

Выведите первый, последний и средний (третий) элемент каждого списка

Измените второй элемент в списке фруктов

Добавьте новый фрукт в конец списка

4. Срезы: Выведите:

Первые три элемента числового списка

Все элементы кроме первого и последнего

Список в обратном порядке

5. Методы списков:

Отсортируйте список фруктов по алфавиту

Удалите последний элемент из числового списка

Вставьте число 0 в начало числового списка

6. Бонус-задача:

Запросите у пользователя 5 чисел, сохраните их в список

Найдите сумму, максимальное и минимальное значение

Выведите список и результаты вычислений
