📘 День 12: Функции (def)
Теория:

1. Функция — именованный блок кода, который можно вызывать многократно.

2. Синтаксис:

python
def имя_функции(параметры):
    # тело функции
    return результат  # необязательно

3. Параметры — переменные, которые получают значения при вызове.

4. return — возвращает значение из функции. Если return нет, функция возвращает None.

✅ Задание 12 (День 12)
Цель: Научиться создавать свои функции и использовать их.

Задачи:

1. Создайте файл lesson_12.py.

2. Простая функция: Напишите функцию greet(), которая принимает имя и выводит "Привет, {имя}!".

3. Функция с возвратом: Напишите функцию square(), которая принимает число и возвращает его квадрат.

4. Функция для проверки чётности: is_even(), возвращает True, если число чётное, иначе False.

5. Функция для суммирования чисел: sum_range(start, end), которая возвращает сумму всех целых чисел от start до end включительно (через цикл).

6. Бонус-задача:

- Создайте функцию calculator(a, b, operation), которая принимает два числа и строку с операцией (+, -, *, /).

- Возвращает результат операции.

- В основной программе запросите данные у пользователя, вызовите функцию и выведите результат. Обработайте деление на ноль и неверную операцию.

Пример работы:

text
=== Функции ===
Привет, Саша!
Квадрат числа 5: 25
Число 7 чётное? False
Сумма от 1 до 10: 55

=== Калькулятор ===
Введите первое число: 8
Введите второе число: 2
Введите операцию (+, -, *, /): *
Результат: 8 * 2 = 16

Подсказки:

- Не забудьте преобразовывать ввод в числа.

- Для операции используйте if-elif-else внутри функции.

- return прерывает выполнение функции.
