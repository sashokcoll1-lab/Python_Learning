📘 Модуль 3: Работа с файлами и обработка ошибок
День 15: Чтение и запись файлов
Теория:

1. Зачем нужны файлы?
Данные, которые вводит пользователь, живут только пока работает программа. Файлы позволяют сохранять информацию (текст, списки, результаты) на диске и использовать её при следующих запусках.

2. Основные операции с файлами:

- Открыть файл: open(имя_файла, режим)

- Прочитать: .read(), .readline(), .readlines()

- Записать: .write()

- Закрыть: .close()

3. Режимы открытия файлов:

- 'r' — чтение (файл должен существовать)

- 'w' — запись (стирает старое содержимое)

- 'a' — добавление в конец

- 'r+' — чтение и запись

4. Конструкция with (рекомендуется):
Автоматически закрывает файл, даже если произошла ошибка.

python
with open("file.txt", "w") as f:
    f.write("Привет, мир!")

5. Чтение всего файла:

python
with open("file.txt", "r") as f:
    content = f.read()
    print(content)

Примерный код для начала (запись и чтение):

python
# Запись
name = input("Ваше имя: ")
age = input("Ваш возраст: ")
with open("user_info.txt", "w", encoding="utf-8") as f:
    f.write(f"Имя: {name}, Возраст: {age}\n")

# Чтение
with open("user_info.txt", "r", encoding="utf-8") as f:
    data = f.read()
    print("Содержимое файла:")
    print(data)

Важно: Используйте параметр encoding="utf-8", чтобы правильно работал русский язык.
