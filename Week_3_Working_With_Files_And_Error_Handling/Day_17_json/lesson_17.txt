📘 День 17: Модули и работа с json
Теория:

1. Модули — это файлы с кодом Python, которые можно импортировать и использовать.

- import random — импорт всего модуля

- from datetime import datetime — импорт конкретной функции

2. Формат JSON — текстовый формат обмена данными, очень похож на словари и списки Python.

- Запись в JSON: json.dump(data, file) или json.dumps(data)

- Чтение из JSON: json.load(file) или json.loads(string)

3. Зачем JSON? В отличие от обычного текстового файла, JSON сохраняет структуру данных (списки, словари, числа), а не просто строки.

Пример:

python
import json

data = {"name": "Саша", "age": 21, "hobbies": ["программирование", "шахматы"]}

# Запись в JSON
with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=4)

# Чтение из JSON
with open("user.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
    print(loaded["name"])

2. Телефонный справочник на JSON:

- При запуске программа загружает контакты из файла contacts.json, если файл есть. Если нет — начинает с пустого словаря.

- Реализуйте меню:

    1. Показать все контакты (имя и телефон)
    2. Добавить новый контакт (имя, телефон)
    3. Удалить контакт по имени
    4. Найти телефон по имени
    5. Выйти (автоматически сохранить контакты в JSON)
- Все изменения должны сохраняться в файл при выходе.

3. Использование модуля os (необязательно):
Проверяйте существование файла contacts.json с помощью os.path.exists() перед загрузкой, чтобы избежать ошибки.

4. Бонус-задача:
Добавьте возможность редактировать номер телефона существующего контакта.

Подсказки:

- Для загрузки данных при старте:

python
if os.path.exists("contacts.json"):
    with open("contacts.json", "r", encoding="utf-8") as f:
        contacts = json.load(f)
else:
    contacts = {}

- Для сохранения данных перед выходом:

python
with open("contacts.json", "w", encoding="utf-8") as f:
    json.dump(contacts, f, ensure_ascii=False, indent=4)
