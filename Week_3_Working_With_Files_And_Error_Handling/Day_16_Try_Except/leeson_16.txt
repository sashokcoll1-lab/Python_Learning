📘 День 16: Обработка ошибок (try-except)
Теория:

1. Исключения (exceptions) — это ошибки, которые возникают во время выполнения программы (например, деление на ноль, отсутствие файла).

2. Обработка ошибок позволяет программе не падать, а красиво сообщить о проблеме и продолжить работу.

3. Конструкция:

python
try:
    # код, который может вызвать ошибку
except SomeError:
    # что делать, если ошибка произошла
else:
    # выполняется, если ошибки не было
finally:
    # выполняется всегда (необязательно)

Пример:

python
try:
    num = int(input("Введите число: "))
    print(10 / num)
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("Делить на ноль нельзя!")

Цель: Научиться обрабатывать ошибки, делая программы устойчивее.

Задачи:

1. Создайте файл lesson_16.py.

2. Деление с защитой:
Запросите два числа у пользователя, выведите результат деления. Обработайте:

- ValueError — если ввели не число

- ZeroDivisionError — если второй ноль

3. Чтение файла с проверкой:
Попросите пользователя ввести имя файла. Попробуйте прочитать и вывести его содержимое. Если файла нет — сообщите об этом и не дайте программе упасть.

4. Список дел с обработкой ошибок:
Доработайте вчерашний список дел: добавьте обработку FileNotFoundError при чтении и PermissionError (на всякий случай).

5. Бонус-задача:
Создайте функцию safe_int_input(prompt), которая запрашивает у пользователя целое число, обрабатывает ValueError и повторяет запрос 
до тех пор, пока не будет введено корректное число. Возвращает int.

Пример работы:

text
=== Деление ===
Введите первое число: десять

Введите первое число: 10

Файл не найден. Проверьте имя.

Введите возраст: 25
Ваш возраст: 25

Подсказки:

- Для обработки нескольких исключений можно записать except (ValueError, ZeroDivisionError):

- Используйте цикл while True для повторного запроса ввода в бонусной задаче.
