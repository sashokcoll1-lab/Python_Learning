📘 День 18: Генераторы списков и модуль random
Теория: генераторы списков (list comprehensions)
Генераторы списков — это компактный способ создания списков на основе существующих последовательностей.

Синтаксис:

python
[выражение for элемент in последовательность if условие]

Примеры:

python
# Обычный способ
squares = []
for i in range(1, 6):
    squares.append(i ** 2)

# Генератор списка
squares = [i ** 2 for i in range(1, 6)]

# С условием (только чётные числа)
evens = [i for i in range(1, 11) if i % 2 == 0]

# С преобразованием
strings = [str(i) for i in range(1, 4)]  # ['1', '2', '3']

Теория: модуль random (напоминание и углубление)

python
import random

random.randint(1, 10)        # случайное целое от 1 до 10
random.choice(["яблоко", "банан", "апельсин"])  # случайный элемент
random.shuffle(список)       # перемешивает список
random.sample(список, k=3)   # выбирает k уникальных элементов
random.random()              # случайное float от 0.0 до 1.0
