📘 День 5: Условные операторы (if, elif, else)
Теория:

1. Условные операторы позволяют программе принимать решения.

2. Синтаксис:

python
if условие:
    # код, который выполнится, если условие True
elif другое_условие:
    # код, если первое условие False, а это True  
else:
    # код, если все условия False

3. Условия — это выражения, которые возвращают True или False:

> (больше), < (меньше)

>= (больше или равно), <= (меньше или равно)

== (равно), != (не равно)

4. Отступы (indentation) критически важны в Python! Код внутри if/elif/else должен быть с отступом (обычно 4 пробела).

✅ Задание 5 (День 5)
Цель: Научиться управлять потоком выполнения программы с помощью условий.

Задачи:

1. Создайте новый файл lesson_5.py.

2. Напишите программу, которая:

Запрашивает у пользователя число

Проверяет:

Если число положительное, выводит: "Число положительное"

Если число отрицательное, выводит: "Число отрицательное"

Если число равно 0, выводит: "Это ноль!"

3. Дополнительная задача: Запросите возраст пользователя и определите:

Если возраст < 13: "Ребенок"

Если 13 <= возраст < 18: "Подросток"

Если 18 <= возраст < 60: "Взрослый"

Иначе: "Пенсионер"

4. Бонус-задача: Создайте простой "калькулятор", который:

Запрашивает два числа

Запрашивает операцию (+, -, *, /)

Выполняет операцию и выводит результат

Если введена неверная операция, выводит сообщение об ошибке

Пример работы программы:

text

Введите первое число: 10
Введите второе число: 5
