День 2: Переменные и типы данных
Теория:

1. Переменная — это "коробочка" с именем, в которой хранится какое-то значение (данные).

2. Присваивание — операция сохранения значения в переменную. Используется знак =.

python
имя_переменной = значение

3. Основные типы данных:

int (integer) — целые числа: 5, -10, 0

float (floating point) — дробные числа: 3.14, -2.5, 0.0

str (string) — строки (текст в кавычках): "Привет", '100'

bool (boolean) — логические значения: True, False

4. Функция type() — показывает тип данных переменной.

✅ Задание 2 (День 2)
Цель: Научиться создавать переменные разных типов и работать с ними.

Задачи:

1. Создайте новый файл lesson_2.py.
