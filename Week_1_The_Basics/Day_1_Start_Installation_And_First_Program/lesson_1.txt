🚀 День 1: Старт! Установка и первая программа
Теория (кратко):

1. Python — это интерпретируемый язык высокого уровня. Это значит, что код выполняется построчно специальной программой (интерпретатором).

2. Редактор кода (IDE) — это программа, где мы пишем код. Для начала отлично подойдет Visual Studio Code (VS Code) или даже онлайн-редактор (например, replit.com).

3. Функция print() — самая важная команда для начала. Она выводит указанную информацию на экран.

Практические шаги:

1. Установите Python: Перейдите на официальный сайт python.org, скачайте последнюю стабильную версию (например, 3.12) и установите её. В процессе установки НЕ ЗАБУДЬТЕ поставить галочку "Add Python to PATH".

2. Проверьте установку: Откройте командную строку (Win+R -> cmd) и введите:

bash
python --version

Должна появиться версия Python.

3. Установите редактор: Я рекомендую VS Code. После установки, можете добавить расширение "Python" от Microsoft.

4. Создайте свой первый файл: Откройте VS Code, создайте новую папку для проекта (например, learn_python), а в ней создайте файл lesson_1.py.

✅ Задание 1 (День 1)
Цель: Написать и успешно запустить свою первую программу.

Задачи:

1. В файле lesson_1.py напишите код, который выводит на экран приветственное сообщение.

2. Добавьте строку с выводом вашего имени.

3. Сделайте однострочный комментарий (#) с текстом "Моя первая программа".

4. Сделайте многострочный комментарий (тройные кавычки ''' или """) с описанием того, что вы чувствуете, начав изучать Python.

Пример того, как может выглядеть ваш код:

python
# Моя первая программа

print("Привет, мир!")
print("Меня зовет Иван.")

"""
Я очень взволнован началом этого пути.
Надеюсь, у меня всё получится!
Сегодня я узнал, что такое функция print().
"""

Ваше действие:

1. Напишите свой код по примеру выше (изменив имя и комментарии).

2. Сохраните файл (Ctrl+S).

3. Запустите программу. В VS Code для этого есть кнопка "Run" в правом верхнем углу или можно нажать F5. Или откройте терминал в папке с файлом и выполните команду:

bash
python lesson_1.py
